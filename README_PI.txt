خطوات تشغيل الراسبري باي للربط مع التطبيق:

1. أين تجد الملفات؟
   - اذهب إلى مجلد المشروع الأساسي: one_piece
   - ستجد مجلداً جديداً قمت بإنشائه لك باسم: raspberry_pi
   - بداخلة ملفين: server.py (الكود) و README_PI.txt (هذا الملف).

2. ماذا تفعل في الراسبري باي؟
   - انقل ملف server.py إلى جهاز الراسبري باي الخاص بك.
   - افتح الـ Terminal في الراسبري باي وقم بتثبيت المكتبات المطلوبة:
     pip install flask flask-cors
   - شغل السيرفر بالأمر التالي:
     python3 server.py

3. ملاحظات هامة للربط:
   - تأكد أن الراسبري باي والموبايل (أو الكمبيوتر) متصلان بنفس شبكة الواي فاي.
   - الـ IP المسجل حالياً في التطبيق هو: 10.113.104.195
   - إذا تغير الـ IP الخاص بالراسبري، قم بتعديله في ملف pi_service.dart في أندرويد ستوديو.
   - بمجرد تشغيل server.py، ستتحول "اللمبة" في التطبيق إلى اللون الأخضر.

4. لتجربة الذكاء الاصطناعي:
   - لا تنسَ وضع مفتاح API Key الصحيح (الذي يبدأ بـ AIza) في ملف ai_service.dart لكي يعمل تحليل الـ PDF بنجاح.
